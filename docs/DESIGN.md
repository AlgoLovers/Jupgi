# DESIGN.md — UI · 테마 · 다이어그램 규약

## 테마 (Material 3, 라이트/다크 필수)

- 팔레트: 종이 톤. 라이트=따뜻한 한지색(`PaperCream`), 다크=먹빛(`DarkSurface`). 강조=계곡 주황
  (`PaperAccent`)·산 파랑(`PaperAccentMountain`). 원전: `core/designsystem/theme/Color.kt`.
- **모든 UI/3D 변경은 라이트·다크 둘 다 검증**(`/emu-qa`). "흰 배경+흰 글씨"류 전면 사고는 한 테마만
  돌렸으면 못 잡는다.
- **알려진 폴리시 항목**: 다크에서 종이 뒷면색(surface)이 배경과 가까워 접힌 면 대비가 약함 →
  렌더러에서 뒷면 전용 색을 지정할 것.

## 반응형 (폰 + 태블릿)

- 콘텐츠는 `widthIn(max = …)`로 상한(현재 뷰어 680dp)을 둬 큰 화면에서 무한정 늘어나지 않게 한다.
- 크기 분기는 하드코딩 dp가 아니라 **WindowSizeClass**로 판단(material3-window-size 포함됨).
- **태블릿 side-by-side**(3D 뷰 + 컨트롤 나란히)는 M1 폴리시 — 지금은 단일 컬럼(폰·태블릿 공용).
- 새 화면은 **컴팩트(폰)·확장(태블릿) 둘 다** 확인.

## 3D 뷰어 (핵심 화면)

- 재생 위치(progress) 슬라이더 = 전체 접기 시퀀스 스크럽(0..stepCount). 이전/처음/다음 버튼 = 단계 이동.
- 카메라: 드래그로 자유 오빗(yaw/pitch). 순수 뷰 상태(화면 로컬 remember) — progress(ViewModel)와 분리.
- 렌더: 화가 알고리즘(깊이 정렬) + 램버트 음영 + 앞/뒷면 색 구분. 도메인이 낸 `PaperMesh`만 그린다.

## 다이어그램 규약 (요시자와·랜들렛 — 가이드선/주석 매핑)

| 규약 | 표기 | 렌더 위치 |
|---|---|---|
| 계곡 접기 | **파선(dashed)** + 화살촉(앞으로) | 3D 크리스 라인(현재 구현) + (이후) 2D 화살표 |
| 산 접기 | **일점쇄선(dash-dot)** + 속빈 화살촉(뒤로) | 동일 |
| 기존 크리스 | 얇은 실선 | 3D 라인 |
| 숨김/X-ray/예정선 | 점선(dotted) | 3D 라인(반투명) |
| 펼치기·회전·뒤집기 | 화살표/기호 | (이후) 2D Compose 오버레이 |

**2단 렌더링 방침**(M1+): 크리스 가이드선은 종이에 붙는 3D 라인, 화살표·라벨·팁·요시자와 기호는
UI이므로 **SceneView/Canvas 위 2D Compose 오버레이**로 그리고 3D 앵커점을 화면좌표로 투영한다.
파선/일점쇄선은 Compose `PathEffect`로 산/계곡을 표현(현재 뷰어가 이미 계곡=파선 적용).

## 접근성

- 팁 텍스트는 Material 타이포 + 충분한 대비. 색만으로 산/계곡을 구분하지 말고 선 패턴(파선/일점쇄선)을
  병행한다(색약 대비).
