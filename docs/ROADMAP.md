# ROADMAP.md — 접기(Jupgi) 방향

> 마일스톤 단위 방향. 세부 진행/다음 액션은 [`STATE.md`](STATE.md).

## M0 · 골격 (완료 — 2026-07-25)

- 순수 Kotlin 폴딩 도메인(로드리게스 힌지 회전) + 유닛테스트.
- Compose Canvas 소프트 3D 뷰어(스크럽·회전·계곡 가이드선·팁).
- 데모 작품 "반으로 두 번 접기". 하네스 전체(스킬·에이전트·rules·훅·워크트리·CI·문서).
- 검증 게이트 초록불 + 에뮬 라이트/다크 눈 검증.

## M1 · 학습 루프 최소 완결 (MVP)

- **작품 라이브러리**: 목록 화면 → 뷰어 네비게이션(navigation-compose). 데모 외 작품 2~4개.
- **FOLD 임포터**: data 계층 FOLD(JSON)→OrigamiModel 변환 + 임포트 테스트. `/add-model` 파이프라인 가동.
- **뷰어 폴리시**: 태블릿 side-by-side(WindowSizeClass), 재생(자동 접기) 버튼, 다크 뒷면색 대비 개선.
- **2D 주석 오버레이**: 화살표·라벨·요시자와 기호를 3D 위 Compose 오버레이로.
- **진행 저장**(Room): 작품별 마지막 단계 기억.

## M2 · Filament 전환 · 품질

- Compose Canvas → **SceneView(Filament)** 렌더러 교체(도메인 불변). 조명·재질·부드러운 종이.
- 복합 접기 지원 확대: 안팎뒤집기·스쿼시. 레이어 순서(faceOrders)·자기관통 처리.
- 접기 베이스(preliminary/bird/frog) 라이브러리.

## M3 · 출시 준비

- 브랜딩(정식 아이콘·폰트), 스토어 리스팅·스크린샷(`/emu-qa`).
- 업로드 키스토어 생성·백업(`/release-aab` 선행 조건), 서명 AAB.
- 온보딩·설정·접근성 마감.

## 검토 중 / 백로그

- 작품 저작 도구(자체 크리스 패턴 에디터 or Oriedita 연동) — 콘텐츠 생산성.
- 사용자 제작 작품 공유(라이선스·검증 파이프라인 필요).
- 손 위치·다음 손동작 힌트, 접기 난이도별 코스.
